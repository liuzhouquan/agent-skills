# Source Code Learning

一个围绕指定技术机制学习真实代码库的 Agent Skill。它不会要求把整个项目读完，而是先确定学习目标和所需掌握程度，再沿源码证据和实验验证目标机制。

## 学习流程

```text
明确目标与掌握层级
    ↓
建立聚焦的知识地图和代码地图
    ↓
追踪文件、符号、调用链和数据流
    ↓
预测、运行、观察、解释、修改与验证
    ↓
评估掌握程度并总结迁移价值
    ↓
持久化状态，供后续会话继续
```

## 掌握层级

1. **知道用途**：能说明机制解决的问题、使用场景和输入输出。
2. **能解释实现**：能根据源码复述关键路径、状态变化、设计选择和边界。
3. **能修改和复现**：能提出或完成有意义的改动，并通过实验或测试解释和复现结果。

每个目标单独记录掌握等级和证据；不以读过代码作为掌握证明。

## 使用示例

```text
用 source-code-learning 帮我理解这个仓库里的请求重试机制。
我想达到“能解释实现”即可，重点追踪从入口到退避计算的调用链。
```

```text
继续上次的源码学习。先读取持久化状态，确认仓库版本和我停下的位置。
```

```text
分析这个实现里有什么设计适合迁移到我的服务，并说明适用条件和需要调整的地方。
```

## 持久化

默认将学习资料放在源码 checkout 外的 `learning/source-code-learning/`，也可由用户指定位置。概览、计划、会话状态和记录模板见 [`references/artifact-templates.md`](references/artifact-templates.md)。新会话先读状态文件并核对仓库 commit；代码版本变化后重新验证受影响的结论。
